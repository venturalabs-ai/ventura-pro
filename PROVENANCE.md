# Provenance

This file records authorship and reference boundaries for `ventura-pro`.

## Ventura-authored material

The OpenCode agent definition, Ventura-specific rules, eval scripts and documentation in this repository are maintained as Ventura Labs AI project material unless a file states otherwise.

## External technologies and references

References to Python, FastAPI, Kubernetes, PySpark, Delta Lake, cloud platforms or other vendors identify technologies or public engineering practices only. They do not imply affiliation, endorsement or certification.

## Eval boundaries

Current automated evals validate structural/contract requirements of the agent and rules. They do not by themselves prove code-generation success rate, vulnerability rate, performance or production readiness. Any future quantitative metric must identify dataset, model/runtime, evaluator, version and commit/release.

## Contribution rule

Before adding copied, translated or adapted third-party material, record source/upstream, URL, version/date when practical, license/terms, reuse type and affected files.
